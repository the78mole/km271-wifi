# Requirements of the ETH-W5500 extension (StrictDoc)

Same structure, grammars and conventions as the main board, see
[`KM217-WiFi/req/README.md`](../../../KM217-WiFi/req/README.md).
UID prefixes: `ETH-SYS-`, `ETH-SYA-`, `ETH-HW-`, `ETH-HWA-`, `ETH-SW-`.
The extension requirements trace to the main board documents
(e.g. `ETH-SYS-001` -> `KM271-SYS-005`, `ETH-SYA-100` -> `KM271-SYA-103`).

Design compliance refers to the repository state of 2025-09-28. Findings of
the production review of 2026-11-25 are listed as requirements with
COMPLIANCE "Not met" or "Partially met".
